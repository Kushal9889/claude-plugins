# agentation (agent-installed)

- **What:** Agent-agnostic visual feedback tool by Benji Taylor for AI coding agents. A React component (<Agentation />) mounts a toolbar in your dev build; click any element (or select text, Cmd/Ctrl-click multi-select, or drag-select), add a note, and get structured markdown back with CSS selectors, element positions, computed styles, source-file paths and the React component tree, so the agent can grep for the exact code instead of guessing from a screenshot. Animation pause freezes CSS/JS/video mid-transition so transient states can be annotated. Two modes: copy the markdown locally, or sync annotations to the agentation-mcp MCP server so the agent reads pending annotations directly (agentation_get_all_pending / watch). React 18+ recommended (16.8+ works), dev/localhost only, desktop browsers. PolyForm Shield 1.0.0.

MCP route: configure the coding agent to run npx -y agentation-mcp server and pass its HTTP endpoint to <Agentation endpoint=... />; the agent then reads annotations itself instead of copy-paste.
