# Anatomy

Claude Code skill that explains a technical idea by building it as a real working object: name an idea in one line and Claude invents a machine that does it, drawn as a live interactive isometric figure (SVG/WebGL) whose numbers come from the same model that moves its parts. Also runs in OpenCode and Codex.

- **Upstream:** https://github.com/wheresryan22/anatomy
- **Type:** skill
- **Source:** Instagram reel by @farhannrakhangi — https://www.instagram.com/reel/DernWRMsBjJ/ (public match; no comment posted)
- **Installed by:** Merlin (Muse) on 2026-10-30

## Ready to use
`npx skills add wheresryan22/anatomy -g -a claude-code  |  then: /anatomy explain how <idea> works, interactive`
