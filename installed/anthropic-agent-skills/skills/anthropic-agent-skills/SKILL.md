# Anthropic Agent Skills (official) (agent-installed pointer)

Documented in Kushal's agent-installed registry from the
2026-11-18 GitHub mining sweep. Installed
from upstream, not vendored here.

- **Upstream:** https://github.com/anthropics/skills
- **Install:** In Claude Code: /plugin marketplace add anthropics/skills, then /plugin install document-skills@anthropic-agent-skills (the production document skills) and/or /plugin install example-skills@anthropic-agent-skills (the example set). No account, API key or payment beyond the existing Claude subscription.
