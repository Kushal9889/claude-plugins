# Brag (/brag)

Claude Code skill that turns the project you just built into a short shareable launch video with music, motion and share copy in one command (/brag), powered by HyperFrames. Reads project code directly; includes a lean /brag-slim variant.

- **Upstream:** https://github.com/latent-spaces/brag
- **Source:** Instagram reel by @aiwithunnati — https://www.instagram.com/reel/Dd1OzxmtvqX/ (public match; no comment posted)
- **Installed by:** Merlin (Muse) on 2026-10-30

## Ready to use
`/plugin marketplace add latent-spaces/brag, then /plugin install brag@brag, then run /brag inside your project (needs Node 22+ and FFmpeg)`
