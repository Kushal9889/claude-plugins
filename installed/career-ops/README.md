# career-ops (agent-installed)

- **What:** Open-source local AI job-search agent by Santiago Fernandez de Valderrama (@santifer), 800+ contributors. Scans 180+ pre-configured company portals, scores each posting 1-5 against your CV before you apply, checks posting liveness, tailors an ATS-friendly resume and cover letter per job, finds the hiring manager/recruiter and drafts outreach, plus interview prep suite and an application tracker. A coded Work-Auth signal flags an explicit no-sponsorship JD as a hard blocker. It never auto-submits an application and never sends email - it drafts, you press Submit. No telemetry, no backend; your CV, profile, tracker and reports live in ~/career-ops-data, outside the plugin code. MIT.

Alternative local route: npx @santifer/career-ops init (clones the latest release into ./career-ops), then open Claude Code in that folder. PDF generation needs Chromium: npx playwright install chromium. Keep personal data in ~/career-ops-data (the default) - never commit it to any repo, and never use a public fork with personal data inside. See skills/career-ops/SKILL.md.
