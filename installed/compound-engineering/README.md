# compound-engineering (agent-installed)

- **What:** Every Inc's workflow plugin for AI coding agents: 37 skills and specialized agents structured as a loop — brainstorm, plan, work, review, then compound — so the knowledge from each change is written down where the next change can read it. Runs on Claude Code, Codex, Cursor and other hosts.
