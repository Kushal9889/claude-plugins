# Higgsfield Skills (agent-installed pointer)

Documented in Kushal's agent-installed registry from the
Instagram reel DfnsFE8z6eL by ngocbuildswebsites. Installed
from upstream, not vendored here.

- **Upstream:** https://github.com/higgsfield-ai/skills
- **Install:** Claude (connector route): Settings > Connectors > Add custom connector > paste https://mcp.higgsfield.ai/mcp > Connect > sign in to Higgsfield (OAuth, no API key). Agent/Claude Code route: install the Higgsfield CLI, run 'higgsfield auth login', then 'npx skills add higgsfield-ai/skills'. Start the 3-day trial at https://higgsfield.ai/mcp (card required, auto-renews - cancel before 72h if not continuing).
