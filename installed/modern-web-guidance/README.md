# modern-web-guidance (agent-installed)

- **What:** Skills that embed modern web-platform expertise into coding agents, stewarded by the Google Chrome, Microsoft Edge, Mozilla Firefox and MDN teams. 262 expert-curated guides (CSS/layout, HTML/DOM, JavaScript/APIs, performance, accessibility, forms, built-in AI, WebMCP and more), eval-pruned so agents stop emitting legacy patterns and reach for native platform APIs with responsible fallbacks. The skill's CLI does offline local semantic search over the guides (no network calls, no API keys) and injects only the targeted guide into context. Evals show +28 to +36pp guided uplift across agents. Code Apache-2.0; guide content CC-BY 4.0.
