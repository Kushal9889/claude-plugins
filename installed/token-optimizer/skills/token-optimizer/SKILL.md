# token-optimizer

Finds ghost tokens burning through your Claude limit and shows the
biggest fixes first. Provides audit, quick scan, dashboard, trends,
and savings reports for Claude Code usage.

## Install

Follow the official setup guide for Claude Code (CLI plugin):

https://token-optimizer.dev/install/overview/

Do not guess install commands; the guide is authoritative and may
change per version.

## Dashboard

After install, the dashboard runs at:

http://localhost:24842/token-optimizer
